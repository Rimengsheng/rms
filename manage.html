使用说明

  1. 在 GitHub → Settings → Developer settings → Personal access tokens 生成一个 Token。
    · Fine-grained token：Repository access 选中 rms，权限 Contents: Read and write。
    · 或 Classic token：直接勾选 repo 权限。
  2. 把 Token 粘贴到页面顶部输入框，点「保存」。Token 只保存在本机浏览器的 localStorage 中，不会上传到任何地方。
  3. 点击上传区选择文件（可多选），或直接把文件拖进虚线框。同名文件会被覆盖更新。
  4. 上传完成后图库自动刷新，点击「复制」即可拿到外链： https://Rimengsheng.github.io/rms/文件名
  5. 若外链打不开，请确认仓库 Settings → Pages 已开启，Source 选择 main 分支 /(root)。
  6. 「删除」按钮会通过 GitHub API 真实删除仓库中的文件，不可恢复。
